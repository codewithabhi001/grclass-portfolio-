# GR Class | Maritime Classification & Certification

A premium maritime classification society platform providing statutory verification, vessel surveys, and digital certification. This platform serves as the digital face for GR Class, ensuring safety, reliability, and compliance in the maritime industry.

## Key Features

- **Class & Statutory Services**: Comprehensive catalog of maritime services.
- **Global Network**: Real-time visualization of regional hubs and surveyor locations.
- **Digital Certification**: Verification system for vessel certificates.
- **Responsive Design**: Premium, mobile-first experience optimized for all devices.
- **Performance**: Built with React and Vite for lightning-fast load times.

## Project Structure

```text
src/
├── app/            # Route-based page components
├── components/     # Reusable UI components (layout, UI primitives)
├── data/           # Static content catalogs (services, offices, news, etc.)
├── features/       # Feature-specific components (home sections)
├── lib/            # Utilities, API hooks, and site configuration
├── assets/         # Static assets and images
└── pages/          # Application entry points and error pages
```

## Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Routing**: React Router DOM

## Getting Started

1. **Clone and Install**:
   ```bash
   npm install
   ```

2. **Development**:
   ```bash
   npm run dev
   ```

3. **Production Build**:
   ```bash
   npm run build
   ```
